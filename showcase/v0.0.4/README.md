# v0.0.4 — 结构化总览 + References + 图表精准裁剪（2026-09-12）

对比 v0.0.3 的两项优化（`insights.md` 为本版效果）：

## 1. 报告格式：结构化总览 + reference 索引

- **总览表格**（`| 编号 | 核心观点 | 出处（章/节）| 页码 | 重要性 |`）替代观点罗列
- 观点统一编号 **[P1]..[PN]** 跨章连续，总览表 ↔ 正文 ↔ References 三处对齐
- 文末 **References 出处索引表**（编号/出处/页码/涉及图表），观点可回溯原文
- 实现方式：编排 prompt 硬性格式指令（F1~F5 + 表格示例 + 提交前自检），
  worker 候选"出处"字段带页码（从 [第N页] 标记读取）

## 2. 图表精准裁剪（不再截整页）

- `app/ingestion/images.py`：页面对象 bbox 空间聚类（gap 22pt），
  每簇外接矩形 = 单个图表区域；页眉/页脚带（80/55pt）种子剔除
  （BIS 页眉装饰线每页出现在 y≈713-779，不滤会多出页眉截图）
- 整页 200DPI 渲染后按 bbox 比例裁剪（PDF 坐标 y 翻转换算）
- 实测 ar2026e：45 页 → 46 张裁剪图，多数单图占页 21~35%
  （原整页 100%，445-570KB → 124-325KB）
- BIS 三联图（Graph N.A/B/C）自然聚为一簇，VLM 可分图解析

## 3. 提速：VLM 描述磁盘缓存

- `runner.describe_section_images`：per source 落盘 `notes.json`
  （图片路径 → 描述），重复提取命中缓存直接跳过（首次 ~7.5min → 秒级）
  ——prompt/格式迭代不再重付 VLM 成本
